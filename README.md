# FundPilot · 理解优先的30天备考路径

中文基金从业学习网站，目标科目一＋科目三。浅色、蓝色点缀、轻量3D因果图，今日只有一个主要入口。

源码公开；现有 Sites 在线实例仍为私人访问。可按下方说明本地运行或自行静态托管。

## 运行与测试

Node.js 20+，无第三方运行依赖。在此目录运行 `npm start`，打开 http://127.0.0.1:4173 。如端口被占用，运行 `PORT=4187 npm start`。`npm test` 执行数据、迁移、计划和计时测试。dist 是完整静态网站，可独立托管；不要直接双击HTML，模块与存储需要HTTP源。

## 怎样学

生活问题 → 三种讲法 → 概念关系与因果推演 → 用自己的话解释 → 按关键点自检 → 少量场景迁移。遇到听不懂可换讲法，也可回到单元列出的前置概念；切换课时分别保留自述草稿。估值与业绩指标单元提供可操作数字模型。

62个单元包括12节金融底座与50节两科精讲。26天学习覆盖两科章节路线；第7、14、21天有阶段检验；第27、28天各有100道自编单选、120分钟计时训练；第29天回到薄弱因果链；第30天混合迁移与考前个人检查。每日计划约30—75分钟，整卷训练另需120分钟。时间为建议，学习日根据真实完成情况推进，不因日历日期自动跳过。

进阶单元包括原文核对任务。讲法帮助理解原理；具体门槛、期限、比例、适用范围及新版条款，须结合官方教材和适用法规核对。原文勾选只是用户自检，不是系统核验。全程路线已安排，不意味着已经全面掌握，也不保证30天通过。

## 记录与计时

课程完成依据因果自述、自检、场景答对与明确保存；保留自述原文。复习按1/3/7/14天间隔安排。错题与未答训练题可回到相应原理，检验完成后显示实际选择和解释。

计时自开始持续，离开页面、关闭或刷新不重置截止时间。恢复时仍使用原题序、答案和截止时间；到期交卷，未答题不计为正确。作答数量和分数只反映自编题，不是官方考试成绩或通过概率。重复训练使用相同题库重新排序，不能视为全新独立测量。

记录存于当前浏览器当前域名localStorage；不会跨设备或跨域同步，清除数据会删除记录。定期从“计划与数据”导出备份。旧12课版本的备份兼容，导入替换前会明确确认。损坏记录暂停写入，可导出原始记录并用有效备份恢复。跨标签页保存会重新载入最新状态。
